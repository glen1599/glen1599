<h2 align="center">🚀 About Me</h2>

<img align="right" src="./assets/f1/car.svg?v=1" width="280" alt="Formula 1 car"/>

So here's the short version: I train models, then build the thing that makes them usable. Most of my work starts with a question nobody asked in a notebook — can a farmer photograph a coffee leaf and get an answer in 20 ms? — and ends with a service, a test suite, and a README that says what it does *not* do.

I like the unglamorous half: the database trigger that keeps stock honest even when a screen forgets, the RLS policy that survives an audit, the global hotkey that works without an Accessibility prompt. F1 is the same obsession in a different shape — telemetry, marginal gains, shipping under a deadline. I don't just watch the races; I read the timing sheets.

Eight public repositories, all built end to end. The flagship ships with 31 tests and mAP@50 98.49 %; the petshop demo runs with 24 verified RLS assertions. Also HackerRank certified in Java, Python and SQL.

**Selected laps:** [Coffee Leaf](https://github.com/glen1599/coffee-leaf-disease-yolov8) · [Zoepy Petshop](https://glen1599.github.io/zoepy-petshop-jogja/) · [Optimization](https://github.com/glen1599/optimization-algorithms-python) · [Library](https://github.com/glen1599/aplikasi-perpustakaan-java) · [AsistenGlen](https://github.com/glen1599/asistenglen) · [more](https://github.com/glen1599?tab=repositories)
